# Standards status

- This package is a **guide**, not a standard. It does not produce a verdict.
- The execution umbrella is
  [`dsh-standards`](https://github.com/PerryLink/dsh-standards): ENTRY/FLOW
  checks, level audit, and the canonical spec files.
- The low-level rule text is
  [`dsh-plugin-spec`](https://github.com/PerryLink/dsh-plugin-spec).
- The legacy build skill/CLI is
  [`dsh-primer`](https://github.com/PerryLink/dsh-primer).

`package.json` carries a `dsh.standards` placeholder with `entry`/`flow` =
`not-run` and `boost` = `not-measured`, `evidence: null`. It is not a pass.

This package is non-official and has no certification, accreditation, security
audit, ranking, or market gate.
